# 白纸图标界面

## 目标

Peri Studio 是工程师长时间停留的 ACP 工作台。界面的任务不是解释自己，而是让项目、对话和 Agent 状态保持可扫读，同时把高频操作压缩到稳定的位置。

本设计以白色为主基调，文字只用于用户内容、对象名称和不可由通用符号准确表达的关键决策。其他动作使用共享描边图标，并通过 tooltip、`aria-label` 和键盘焦点提供完整语义。

## 视觉系统

- **Paper `#FFFFFF`**：应用、侧栏、卡片和输入区的主表面。
- **Whisper `#FAFAF9`**：仅用于代码、用户消息和小面积选中反馈。
- **Hairline `#E9E9E6`**：用一像素分隔结构，替代大块灰色背景。
- **Ink `#1F1F1D`**：正文和主要图标。
- **Graphite `#767671`**：辅助图标及元数据。
- **Signal `#25865A`**：在线、完成等小面积状态点；警告与错误遵循同一限制。

字体继续使用系统 UI 字体承担正文，等宽字体只承载代码和精确标识。基础字号为 14px，工具栏和元数据使用 10–12px。

## 布局

```text
┌──────────────┬────────────────────────────────────┐
│ ✣  ＋  ⌕  ◌ │ 会话标题                 •  •  ⚙ ⋯ │
│ ⑂  ▦  ◷  ⌁ │────────────────────────────────────│
│ 项目名称     │                                    │
│  └ 会话名称  │         对话正文                   │
│              │     [ Todo · Async · Changes ]     │
│              │     [ assets                       ]│
│ A       〽 ? │     [ 输入内容               ✦ ↑ ] │
└──────────────┴────────────────────────────────────┘
```

项目和会话名称必须保留文字，因为它们是导航对象；侧栏顶栏、底栏、对话头和输入工具栏均采用图标优先。权限卡保留请求标题和必要描述，允许、拒绝、重试收敛为带 tooltip 的圆形图标动作。

## 交互约束

1. 图标按钮必须使用共享 `IconButton`，不得只依赖 `title`。
2. 不可用功能保持图标占位，但降低不透明度并说明未连接原因。
3. 状态默认显示为 5–7px 色点；完整文案放入可访问名称或 tooltip。
4. 警告、错误和成功不得铺满大面积背景，只使用边框、图标或状态点。
5. 破坏性或不可逆操作若图标存在歧义，确认弹窗仍保留明确动词。
6. 移动端触控目标不得小于 44px；桌面端视觉图标可为 28–36px。
7. 桌面端文件与 Git 工作台展开为覆盖会话的浮动纸面，只保留 46px 活动轨参与布局；展开和收起不得改变消息流、权限卡或输入框宽度。移动端继续使用模态抽屉。
8. Status Area 固定在输入框上方，使用 Todo、Async、Changes 三个标签；计划与异步任务分开，Async 以 Agent、Workflow 标识来源。阻塞式提问出现时让位，会话结束后仅在仍有文件改动时保留。
9. Composer 的 assets 行位于正文输入上方，只承载待发送的文件、图片和引用预览；真实环境无暂存内容时整行隐藏。
10. 工具调用在正文中使用无卡片底色的紧凑任务行，默认折叠输入与输出；状态图标、短参数和代码入口必须在单行内可扫读。
11. 不再提供 VS Code 风格的全局底部状态栏；连接状态留在会话头，文件入口由资源活动轨和移动端会话头承担。
12. 产品图标统一来自 `lucide-solid`，默认使用 1.7–2px 线宽；完成态只使用绿色对勾，运行态只使用小型空心圆，不得用粗圆环或大色点替代。

## 移除条件

若可用性测试证明某个图标在无标签情况下持续被误解，应为该动作恢复短标签，而不是引入新的彩色卡片或长说明。
